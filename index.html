FCR % – First Call Resolution

FCR % = share of calls that did NOT come from a repeat number. A repeat number is a number that called the minimum number of times (the Repeat setting, default 3) within the same day, week, month or 3-day cycle (Cycle 1 = days 1–3, Cycle 2 = days 4–6 ... Cycle 10 = day 28 to month end). Higher is better. Uses the same call filters as the other tabs.
